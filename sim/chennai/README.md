# Thousand Lights SUMO network

The review web demo routes over the checked-in `roads.json` graph. This directory
also contains a working SUMO 1.27.1 scenario with random background traffic and
one ambulance from the approximate Nungambakkam start point to Apollo Hospitals
on Greams Road. SUMO's static traffic-light programs run in the network; the
ambulance does not yet request green lights through ResQ/TraCI, and the web
dashboard is not yet driven by this SUMO stream.

The generated network is intentionally not committed because OpenStreetMap data
changes and the exact junction corrections must remain reviewable. From this
workspace, run:

```powershell
.\scripts\sumo.ps1 -Build          # rebuild and launch the GUI
.\scripts\sumo.ps1 -Headless       # quick TraCI verification
```

The builder discovers the project-local SUMO installation automatically. A fresh
environment can install it with `pip install -e ".[sumo]"`.

`sumo-gui -c sim\chennai\chennai.sumocfg` also works directly after a build.

The network builder also creates `generated/landscape.poly.xml`,
`generated/ambulance.rou.xml`, and `generated/scenario.add.xml`. The ambulance
route in `ambulance.rou.xml` is generated by the repository's Dijkstra router
using free-flow SUMO edge travel times. OSM buildings, parks, and land-use areas
use the palette in `landscape.typ.xml` to provide map detail behind darker roads.
The scenario file labels the approximate ambulance start and Apollo Hospitals
destination and draws the planned route in green. Vehicles use SUMO's
constant-size-when-zoomed-out mode, so they remain visible at overview scale and
return to road scale as you zoom in. The signal timings are generated estimates
and have not been field-verified.

The checked-in bounding box is the project starting point around Apollo Hospitals,
Greams Road. Before collecting final results, inspect every signal, one-way, turn
restriction, and the Gemini flyover in `sumo-gui`; store corrections as plain-XML
patches rather than editing the generated `.net.xml` directly.

Generated files are placed under `sim/chennai/generated/` and ignored by Git.
The direct OSM API download and generated network may report incomplete transit
relations and geometry warnings at the bounding-box boundary. Those warnings do
not prevent the demo run, but they must be reviewed before research measurements.
